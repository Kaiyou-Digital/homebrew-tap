# homebrew-tap

Homebrew tap for distributing [marka](https://github.com/muchbetteradventures/homebrew-tap) and [Shelve](https://github.com/muchbetteradventures/homebrew-tap).

**Note:** this repo is just the Homebrew Cask manifests (the "how-to" for installing via `brew install`). It is not the source code for either app — that lives in their own repos (marka, shelve / shelve-ios / shelve-chrome).
